============
Installation
============

..  code-block:: bash

    composer require goldene-zeiten/products-personalization

Update the database schema, then add the site set :guilabel:`Products Personalization` to your site, or
include the static template :guilabel:`Products Personalization` in a :sql:`sys_template` record. Either
adds the option fields to the add-to-basket forms of the product detail page.
