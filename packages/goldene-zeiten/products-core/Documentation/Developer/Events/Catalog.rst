=======
Catalog
=======

Events fired during catalog operations and category tree building.

ModifyProductListEvent
----------------------

Lets integrators narrow a built-in product list before it is queried and paged - hide
out-of-region items or restrict a list to a brand. Build a constraint with the list's query and
add it; the list shows the products matching every added constraint. Because the constraints
become part of the query, the page count stays right. :php:`getCriteria()` tells which list
mode, selection and sorting the element uses.

Listings an add-on registers through :php:`ProductListModeProviderInterface` select their
products themselves and do not dispatch this event.

Mutable: Yes (via ``addConstraint(ConstraintInterface $constraint)``)

Example listener:

..  code-block:: php

    #[AsEventListener]
    final class OnlyProductsOfTheCurrentRegion
    {
        public function __invoke(ModifyProductListEvent $event): void
        {
            $query = $event->getQuery();
            $event->addConstraint($query->in('uid', $this->productUidsSoldIn($event->getRequest())));
        }
    }

ModifyCategoryQueryEvent
------------------------

Lets integrators constrain or reorder the category query behind the catalogue navigation - restrict by user group,
hide seasonal categories, or apply dynamic filters. The query is mutated in place by listeners
(e.g. ``$event->getQuery()->matching(...)``).

Mutable: Yes (in place via ``QueryInterface`` mutation)

Example listener:

..  code-block:: php

    #[AsEventListener]
    final class RestrictCategoriesByUserGroup
    {
        public function __invoke(ModifyCategoryQueryEvent $event): void
        {
            $query = $event->getQuery();
            // Constrain the query to filter or reorder categories
            $query->matching($query->equals('hidden', 0));
        }
    }

ModifyCategoryTreeEvent
-----------------------

Lets integrators reshape the built category tree - reorder branches, prune empty categories,
or inject virtual nodes for dynamic catalog navigation.

Mutable: Yes (via ``setTree(CategoryTreeNode[] $tree)``)

Example listener:

..  code-block:: php

    #[AsEventListener]
    final class ReshapeCategoryTree
    {
        public function __invoke(ModifyCategoryTreeEvent $event): void
        {
            $tree = $event->getTree();
            // Reorder, prune, or augment the category tree structure
            $event->setTree($tree);
        }
    }

Customising product links
--------------------------

Product URLs are generated by Fluid (``f:link.action``) together with the route enhancers,
so there is deliberately no event for them. Customise them by overriding the ``Product/ListItem``
partial (or the other product-link partials) or by adjusting the route enhancer configuration.
